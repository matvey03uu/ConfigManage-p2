# Конфигурационное управление (вариант 20)

Минимальный CLI-прототип инструмента визуализации графа зависимостей
пакетов.

## Этап 1

Программа принимает шесть параметров командной строки, проверяет их и
выводит в формате `ключ: значение`. На этом этапе получение зависимостей
и построение изображения ещё не реализованы.


## Параметры

| Параметр | Назначение | Проверка |
|---|---|---|
| `--package` | Имя пакета | Не пустое |
| `--repository` | URL репозитория или путь к тестовому файлу | Проверяется с учётом режима |
| `--test-mode` | `true` для тестового файла, `false` для URL | Только `true` или `false` |
| `--version` | Версия пакета | Числа, разделённые точками |
| `--output` | Имя выходного файла | Только имя файла с расширением `.svg` |
| `--max-depth` | Максимальная глубина | Целое число не меньше нуля |

## Запуск в Windows

При запуске данной команды в терминале:

```bat
.\run.bat --package A --repository tests\repository.txt --test-mode true --version 1.0 --output dependencies.svg --max-depth 2
```

Выводом будет:

```text
package: A
repository: tests\repository.txt
test_mode: true
version: 1.0
output: dependencies.svg
max_depth: 2
```

## Тестирование

Для проверки корректности работы программы используются автоматические тесты на основе стандартной библиотеки Python `unittest`.

Тесты находятся в директории `tests/`, в файле `test_config.py`.

### Запуск тестов

Из терминала проекта выполняется команда:

```bat
python -m unittest discover -s tests -v
```

### Проверяемые случаи

В ходе тестирования проверяются:

- корректная обработка всех обязательных параметров командной строки;
- принятие корректного URL репозитория;
- проверка существования тестового файла репозитория;
- обработка отрицательного значения максимальной глубины;
- обработка нечислового значения максимальной глубины;
- проверка формата версии пакета;
- проверка имени выходного файла и его расширения;
- обработка некорректного URL репозитория;
- обработка отсутствующих обязательных параметров.

### Результат тестирования

Если все тесты пройдены успешно, в терминале отображается сообщение:

```text
Ran 10 tests
OK
```

Сообщение `OK` означает, что все автоматические тесты завершились успешно.

Если тест обнаруживает ошибку, `unittest` выводит информацию о неудачном тесте и причину сбоя.
